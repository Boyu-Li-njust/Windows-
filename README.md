# 桌面待办

桌面待办是一款运行在 Windows 桌面上的本地任务清单组件。它借鉴 DesktopCal、Rainlendar 和敬业签的任务体验，但不以日期、月历或时间轴为核心，而是以“随时可见、快速处理任务”为目标。

软件以透明桌面组件的形式常驻桌面，可设置始终置顶、调整透明度、固定窗口位置，并支持清单、分组、主任务和子任务的层级管理。数据默认保存在本机，不需要账号和多端同步。

## 已实现功能

### 任务管理

- 快速新增主任务。
- 每个主任务右侧提供仅显示 `＋` 的子任务入口，可直接连续新增子任务，支持两级任务结构。
- 主任务和子任务均可勾选完成，已完成任务可以再次点击恢复为未完成。
- 删除任务后进入回收站，支持撤销删除。
- 主任务和子任务均支持右键设置截止时间。
- 支持显示或隐藏已完成任务。
- 支持拖拽任务排序、跨分组移动；移动主任务时会携带其子任务。
- 支持将任务拖到另一个主任务上，使其成为子任务。

### 清单与分组

- 支持创建多个任务清单和任务分组。
- 每个分组标题后都有 `＋`，可直接在对应分组新增任务。
- 清单和分组均支持右键重命名、删除等操作。
- 清单支持鼠标左键拖拽排序，清单较多时支持鼠标滚轮滚动。
- 删除清单或分组前会弹出确认对话框，可选择任务处理方式。

### 桌面窗口

- 支持完整任务框图和透明桌面常驻显示。
- 支持始终置顶或普通窗口层、透明度调整、锁定窗口位置。
- 支持拖动标题栏移动窗口。
- 点击右上角关闭按钮会退出应用进程；临时隐藏可使用系统托盘显示/隐藏。
- 设置菜单点击外部会自动关闭。

### 悬浮图标模式

点击顶部缩小按钮后，窗口会真正缩小为 `76×76` 的悬浮图标窗口：

- 使用黑底白色眼睛和灰色勾选图案。
- 悬浮图标固定保持在最上层，不提供普通窗口层切换。
- 鼠标左键按下并持续拖动可移动图标，松开即停止；锁定位置后不可拖动。
- 鼠标悬停时，图案本身显示紧贴边缘的高亮效果。
- 双击图案会在悬浮图标当前所在位置恢复完整任务框图，不会跳回缩小前的旧坐标。
- 右键图案可设置透明度或直接恢复窗口。

### 启动与快捷操作

- 支持创建桌面快捷方式，快捷方式使用与悬浮图标一致的图案，双击即可直接打开任务框图。
- 支持 Windows 开机自启动。
- `Ctrl + Alt + T`：显示组件并聚焦快速新增。
- 快速新增输入框按 `Enter` 保存；子任务输入框可连续新增。
- `Tab` 将当前主任务缩进为上一条主任务的子任务，`Shift + Tab` 将子任务提升为主任务。

## 数据与隐私

软件采用本地优先设计：任务、清单、分组和窗口设置保存在本机用户数据目录；不要求登录、不依赖云端服务，也不进行多端同步。

## 运行

```powershell
npm install
npm start
```

`npm install` 只负责安装依赖，不会打开应用。正常启动后窗口会显示在桌面右侧；关闭按钮会隐藏窗口，可通过系统托盘图标重新显示。

如果窗口未出现，可运行带日志的启动命令并查看终端输出：

```powershell
npm run start:debug
```

`npm install` 只负责安装依赖，不会自动打开应用。

## 快捷操作

- `Ctrl + Alt + T`：显示组件并聚焦快速新增。
- `Enter`：在快速新增框中保存任务；在子任务输入框中连续新增。
- `Tab`：将当前主任务缩进为上一条主任务的子任务。
- `Shift + Tab`：将子任务提升为主任务。
- 点击每个分组标题右侧的 ＋，在该分组中连续新增任务。
- 拖动任务右侧的 ⠿ 到目标分组标题：移动任务，主任务携带子任务一起移动。
- 将 ⠿ 拖到另一个主任务上：设为其子任务。

右上角关闭按钮会退出应用进程；如果只想暂时隐藏组件，请使用系统托盘中的“显示／隐藏”。

## 当前验证状态

项目当前已通过 `npm run check` 和 `npm test`。自动化测试覆盖任务完成状态反复切换、保存竞态、任务分组移动、默认数据、损坏数据恢复以及任务层级排序等核心逻辑。

## 产品定位

桌面待办的核心不是记录某一天要做什么，而是把当前真正需要处理的任务放在桌面上。用户可以按照清单和分组组织工作，在不打开复杂管理软件的情况下完成新增、勾选、拆分、移动和回收；悬浮图标模式适合希望保持桌面整洁、但仍需要一键恢复任务清单的场景。
